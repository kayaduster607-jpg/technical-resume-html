# v28 风格的 HTML 与打印实现

制作或修改 HTML 时读取。用户指定现有 HTML 时以该文件为准；模板是新建起点。

## 视觉与结构

| 部分 | 建议起点 | 说明 |
| --- | --- | --- |
| 纸张 | A4，210 × 297mm | 打印 `@page` 设 A4、零外边距，内部留白由页面 padding 管理 |
| 正文 | 9.5pt，行高 1.4 | 沿用中文无衬线字，允许按实际版面调整；不靠极小字容纳溢出 |
| 留白 | 上下 9mm，左右 10.6mm | 页脚另预留空间 |
| 主色 | 深蓝 `#174a7c` | 一级内容标题浅蓝底、左边线；正文近黑色 |
| 页数 | 核心经历优先，参考两页 | 内容不足不硬凑两页，重要内容确实多则增页 |
| 标题 | `h1` 姓名、`h2` 栏目、`h3` 经历 | 原生文字与列表，维持线性阅读和可复制性 |

`main > .page > .page-content` 是模板和检查器约定。`.page-num` 不放在 `.page-content` 内。每个 `.page` 为一个计划打印页；所有应保留的内容都放进 `.page-content`，防止漏检。

经历节点使用 `.item`，包含 `.item-head`（标题与日期）、`.project-summary`、`.tech`、职责列表与成果列表。职责列表每个具体技术点采用“问题＋解决＋提升效率”，三个部分在同一条内连贯表达；成果列表只作项目整体汇总。只加粗机制和效率／效果要点，避免整行大面积加粗。技能分类和实际项目对应，避免堆砌无证据的技术名。

保持单列主阅读顺序。照片为可选，用户没有提供时删除照片区域并调整头部，不自动生成头像。不需要照片、个人优势或某项证书时直接删去对应模块。

## 分页与溢出

- 页面采用固定计划尺寸，但 `overflow: visible`；排版失败应露出并被检查到，不能默默截去。
- 实际边界检查应逐个检查可见子元素、正文尾部、横向宽度与页脚区域，不能只比较固定高度元素的 `clientHeight`。
- 经历项目优先整体换页；过长时只在语义边界拆分，并标明“续”，避免孤立小标题。`break-inside: avoid` 不保证任意长内容都能放得下。
- 打印工具栏、照片输入与状态提示隐藏。最后一页不强制分页，避免空白尾页。
- 导出设置为 A4、100% 缩放、关闭浏览器页眉页脚；不要靠“缩放到合适大小”掩盖源版面错误。
- 修改后在屏幕和打印媒体中分别测量，再导出 PDF 核对实际分页。浏览器字体加载完毕后才测量。

## 本地交互与维护

- 模板无需联网，不依赖框架、CDN 或外部字体。
- 照片使用原生文件选择与本地预览；上传预览只存在当前会话。若需要单文件携带照片，由制作步骤将用户提供照片的 data URL 写入新 HTML；不声称 localStorage 会随文件共享。
- 文件类型检查、读取失败处理和可访问的按钮标签保留。照片不发送远程服务。
- 禁止将用户文本拼进 `innerHTML`；以文本节点或正确转义填充。
- 新增交互写小函数并加必要注释；新增经历复用语义结构，不持续追加互相覆盖的 CSS。

## 验证脚本

先定位现有 Node.js、Playwright 和浏览器；Codex 桌面可通过 `load_workspace_dependencies` 获得运行时路径。无需为本 skill 全局安装依赖。

```text
node scripts/validate_resume.cjs <resume.html> --out <qa-directory>
```

依赖不在默认解析路径或浏览器不在默认位置时：

```text
node scripts/validate_resume.cjs <resume.html> --out <qa-directory> --playwright-module <absolute-playwright-directory> --browser-executable <absolute-chromium-executable>
```

脚本仅访问指定 HTML、其本地资源和输出目录，不读取 `.env`。输出 `report.json`、每页屏幕与打印截图、`resume.pdf`。字体等待和原生图片加载完成后再测量；浏览器错误、越界、外链资源、未填写标记、隐藏文字或打印未隐藏的工具栏会记为失败，退出码为 1。

检查器要求存在 `.page-content`。检查旧版 HTML 时，在副本中给计划正文增加此包装，或使用同等逐节点边界检查；不能为了通过检查把内容移出受检区域。

脚本不能判断经历真伪、措辞质量、字体审美或 PDF 内的文字提取是否正确。运行后仍需查看逐页截图，抽取 PDF 文字检查可选性与缺字，并比较 PDF 页数和计划页数。模板照片预览和打印按钮至少手动或自动操作一次。

只有 skill 模板自身保留 `【字段】` 标记。用于投递的成品必须全部替换或删除；验证模板时显式加 `--allow-template-markers`，不能用该参数为投递成品放行。
